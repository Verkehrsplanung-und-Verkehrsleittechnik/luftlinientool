Parameters
sourceFilename (str) or Visum instance
attr_cflName of the zone attribute that contains the categorization in OZ,MZ,UZ ... Default: TypeNo
dict_cflDictionary containing the attribute values for the respective VFS
max_distanceSpecification of the distance up to which neighbors will be connected
no_suppliersSpecification of how many higher-ranking centers a zone should be connected to
attr_origName of the attribute that indicates whether the zone is considered as a source. Default: None
attr_destName of the attribute that indicates whether the zone is considered as a destination. Default: None
use_filterIndicates whether only active zones are considered. Can only be used if source = Visum instance
formula_distanceDefines the distance function for determining the supply centers. Note: For triangulation, the air-line connections are determined using the Euclidean distance. Delaunay triangulation only works with a projection of Lat/Lon coordinates.
path_outputOptional possibility to specify a path for file export. Default: None. Then the current folder is used if needed.
translatorOptional Translator instance for multilingual logging.
