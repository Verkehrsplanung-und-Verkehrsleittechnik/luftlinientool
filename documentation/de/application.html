Luftlinientool (LLT) / Direct-Line Network Tool (DLNT)

Erstellen von Luftlinienverbindungen für gegebene Verkehrszellen (= Bezirke) eines Verkehrsmodells in PTV Visum anhand der RIN.

Anwendung

Anwendung via graphischer Benutzeroberfläche (GUI)

Zwei Möglichkeiten

  • Visumversion ist noch geschlossen:
    GUI extern starten (dlnt_GUI.py ausführen)
  • Visumversion ist bereits geöffnet:
    • Das Ausführen der GUI (dlnt_GUI.py) in das Skriptmenü integrieren
    • Skript via Skriptmenü starten

    Hinweis: Wenn die GUI mehrmals gestarten & beendet wird, erscheint eine Fehlermeldung. Diese kann ignoriert werden, die Funktionalität ist trotzdem gegeben.

Aufruf via Code

Das Luftlinientool kann auch ohne GUI angewendet werden. Dazu muss als Codeausführung eine Instanz der Klasse DirectLineNetworkCalculator erstellt werden.
Danach kann auf die Methoden der Instanz (Import, Berechnung, Export) zugegriffen werden.
Ein Beispiel ist unter example_application_wo_gui.py zu sehen.

Notwendige Verfahrensschritte

  1. Parameter setzen (welche VFS, Attributswerte etc.)
  2. Eine Instanz des DirectLineNetworkCalculator initialisieren
    • Code: Aufruf Konstruktor mit Parameterübergabe
    • GUI: "Daten einlesen" in Toolbar ausführen
  3. Luftlinienverbindungen berechnen/erzeugen
    • Code: Aufruf calculate_main Methode
    • GUI: "Berechnung Luftlinien-Netz" in Toolbar ausführen
  4. Ergebnisse in gewünschter Form in das Modell exportieren
    • Code: Aufruf der export_matrix/export_net Methode
    • GUI: Die entsprechenden Buttons (Mtx/Net) in der Spalte "Export nach Visum als" verwenden.
      Alternativ überträgt der Button "Export nach Visum alle VFS: Strecken und Matrizen" die kombinierten Ergebnisse aller Verbindungsfunktionsstufen.

Anmerkungen

  • Bei der GUI werden aktuelle Berechnungen zurückgesetzt, wenn die Auswahl eines der Bezirksattribute geändert wird. Dabei wird eine neue Instanz des DirectLineNetworkCalculator erstellt.
  • Werden Bezirkswerte in Visum geändert, werden diese nicht automatisch im DirectLineNetworkCalculator geändert. Deshalb muss der Verfahrensablauf ab Schritt 2 wieder ausgeführt werden.
  • Die initialen Parameterwerte können in der GUI über das Tool "Defaultwerte" wieder aufgerufen werden.
  • "Ergebnisse initialisieren" ermöglicht das Löschen bereits vorhandener Ergebnisse.
  • Schritt 3 verwendet die aktuell in der GUI eingegebenen/in der DirectLineNetworkCalculator-Instanz definierten Parameter. Vor der Rechnung mit neuen Parametern empfiehlt sich das Löschen der vorhandenen Ergebnisse ("Ergebnisse initialisieren").

Voraussetzung

Verkehrsmodell in PTV Visum mit kategorisierten Bezirken:

  • Attribut für die Zentralität der Verkehrszellen (Visum: Bezirke): je kleiner die Zahl, desto größer ist die Zentralität des Bezirks

    Bsp.: Angabe der Zentralität über die Typnummer

    • 0 ... Metropolregion
    • 1 ... Oberzentrum
    • 2 ... Mittelzentrum
    • 3 ... Grundzentrum
    • 4 ... Ort ohne zentrale Funktion
    • 5 ... Teilort
  • (optional) aktiver Bezirksfilter
  • (optional) Angabe eines Attributs, welcher Bezirk als Quelle verwendet werden soll {0=Nein, 1=Ja}
  • (optional) Angabe eines Attributs, welcher Bezirk als Ziel verwendet werden soll {0=Nein, 1=Ja}
